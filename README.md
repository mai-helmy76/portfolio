# Mai Helmy — three portfolios, one GitHub Pages repository

Upload these files to https://github.com/mai-helmy76/portfolio using the current `main` branch and Pages source `main` / `(root)`.

- `/index.html` → https://mai-helmy76.github.io/portfolio/ (Arabic visual art and art-based therapy)
- `/en/index.html` → https://mai-helmy76.github.io/portfolio/en/ (English visual art and art-based therapy)
- `/teaching/index.html` → https://mai-helmy76.github.io/portfolio/teaching/ (English art education / teaching)
- `/teaching/Mai_Helmy_Art_Teacher_CV_Revised.pdf` → the teaching CV download

`index.html.html` is an unrelated duplicate currently visible in the public repository and may be removed after ensuring that `index.html` is present.

## GitHub website upload
1. Sign in to GitHub and open the repository above.
2. Click **Add file > Upload files**.
3. Open this extracted folder on your computer and drag the *contents* (not the outer folder) into GitHub. This includes `index.html`, `en/`, `teaching/`, and `.nojekyll` (hidden; not required). Include README if useful.
4. Check that the pending files are under `en/index.html` and `teaching/index.html` and NOT under `Mai_Helmy_Three_Portfolios_GitHub_Pages/en/...`.
5. Add a commit message and click **Commit changes** to the `main` branch (or use a review PR if GitHub requires it).
6. Go to Settings > Pages > Build and deployment. Keep `Deploy from a branch`, branch `main`, folder `/(root)`. Save if changed.
7. Open the three URLs above after deployment. If a page is temporarily missing, check Actions for deployment status.

## Notes
- Artwork is embedded in the HTML; no external image folder is required.
- No language proficiency listings appear in the portfolio pages.
- Do not upload children's identifiable photographs or sensitive therapeutic records without appropriate authorisation and informed consent.
- The Art Teacher page includes a PDF CV, so keep `teaching/Mai_Helmy_Art_Teacher_CV_Revised.pdf` beside it.
